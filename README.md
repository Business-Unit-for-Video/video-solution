# 视频处理自动化管道

一个完整的 YouTube 视频下载、转写、分段、翻译、配音和对口型的自动化工具链。

当前 Q1 新主线是高考数字人短视频与半自动直播。第一阶段先通过版本化内容包锁定来源、审批、授权、风险转人工和归因，再接入数字人渲染供应商。参见 [`docs/gaokao-pilot.md`](docs/gaokao-pilot.md)。

## ✨ 功能特性

- 📥 **批量下载**: 获取 YouTube 频道所有视频（区分直播/回放）
- 🎤 **高精度转写**: WhisperX + 词级时间戳 + 说话人分离
- 📑 **智能分段**: 自动识别停顿 + LLM 生成章节标题
- 🌍 **AI 翻译**: GPT-4 时长约束翻译
- 🗣️ **声音克隆**: GPT-SoVITS / Coqui TTS 仅需 1 分钟音频
- 🎭 **对口型**: Wav2Lip 视频唇形同步
- 📝 **双语字幕**: 中英文字幕烧录
- 🚫 **敏感词过滤**: 自动检测并消音/哔声
